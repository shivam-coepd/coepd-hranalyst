# HRAnalyst Placement Wing

Production placement-management platform for HRAnalyst.

## Product Panels

- Admin / Super Admin
- Placement HR
- Client HR
- Student

## Stage 1 Scope

Stage 1 establishes:

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase project foundation
- Profile schema
- RBAC schema
- Company schema
- Client HR profile schema
- Placement HR profile schema
- Student profile schema
- Audit log schema
- Private storage buckets
- Auth-user profile trigger
- Canonical application constants

Authentication flows and authorization guards are implemented in Stage 2.

## Requirements

- Node.js 22+
- npm
- Supabase project
- Supabase CLI
