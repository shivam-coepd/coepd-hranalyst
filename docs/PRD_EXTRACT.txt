1. Product Overview

Problem: Manual placement process via portals, WhatsApp, sheets leads to delays, no tracking, no verification of existing students, no client visibility.Solution: 3-Panel Platform - Admin Panel (Super Admin creates/approves users), HR Panel (Placement HR internal + Client HR external), Student Panel (Job Seekers). Goals: JD to Submission <24hr, 90% verification accuracy, 100% interview tracking.

4. Functional Requirements

FR-01 User Management: Admin creates users {name,email,role,company_id/enrollment_id}. Approval workflow Pending->Approved/Rejected. Student validation via enrollment_id check against HRAnalyst DB. Company validation via domain.FR-02 Job Management: Client HR posts job with fields job_title, role_type, location_type, location, experience, jd_text, salary_range. Status draft, pending_checklist, published, closed.FR-03 Checklist Generator: Placement HR creates checklist linked to job_id. Fields must_have JSONB, good_to_have JSONB, tools JSONB, domain, exp_required. AI assist button to auto-generate from JD using OpenAI.FR-04 Publishing: Publish job to Student Panel, generate poster payload {title, company, role_type, top_3_skills, exp}, broadcast flags.FR-05 Application: Student job feed cards with match% badge, Apply modal with CV upload, ATS score preview. Table applications with UNIQUE(job_id, student_id).FR-06 Verification: Queue list, CV viewer split view, match% calculation, ATS score, actions Verify/Reject.FR-07 Submission: Select verified, submit to client, notification.FR-08 Mock: mock_interviews table, calendar UI, scorecard form.FR-09 Shortlisting: Client view submitted profiles cards, Shortlist/Reject buttons.FR-10 Interview: interviews table, scheduling form, calendar invite, notifications.FR-11 Feedback: feedbacks table, rating, decision, comments, offer upload, status update to Placed.

5. Business Logic & Calculations

Match Score = (must_matched/total_must * 70) + (good_matched/total_good * 20) + (tools_matched/total_tools * 10)ATS Score = 20% contact info + 30% skills + 20% experience + 15% formatting + 15% length (0-100)Existing Student Check: enrollment_id must exist in external HRAnalyst student DB/API else block with message "Only existing HRAnalyst students can apply"Quality Gates: No submit if match <60%, No publish without checklist, Mock mandatory before client interview, Feedback logged within 24hr

6. API Endpoints

POST /api/users - Admin - Create user - Body {name,email,role,company_id/enrollment_id}

PUT /api/users/:id/approve - Admin - {status: approved/rejected, reason}

POST /api/jobs - Client HR, Placement HR, Admin - {title, role_type, location_type, location, experience, jd_text, salary_range, company_id}

POST /api/checklists - Placement HR - {job_id, must_have[], good_to_have[], tools[], domain, exp_required}

POST /api/jobs/:id/publish - Placement HR, Admin - Publish to student panel

POST /api/applications - Student - {job_id, cv_url}

PUT /api/applications/:id/verify - Placement HR - {status, match_score, ats_score, reason}

POST /api/submissions - Placement HR - {application_ids[], job_id}

POST /api/mocks - Placement HR - {application_id, scheduled_at, mode}

PUT /api/applications/:id/shortlist - Client HR - {decision: shortlisted/rejected_client, reason}

POST /api/interviews - Client HR - {application_id, round, scheduled_at, location_or_link}

POST /api/feedbacks - Client HR, Placement HR - {application_id, rating, decision, comments}
